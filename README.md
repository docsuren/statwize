# Statwize – statistics for medical research

Choose the right statistical test, check its assumptions, compute the result and write it up. Design data-entry forms with built-in error checks (like Epicollect5), open a CSV or Excel file to view and edit the data, run tests of significance and draw publication-ready charts, as in jamovi or JASP.

Website: https://docsuren.github.io/statwize/  ·  Android app: Statwize.apk (version 1.2)
